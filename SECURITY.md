# Kaythem fork security reporting

This maintained branch is experimental and is not a production-qualified
cryptographic release. Its public availability does not imply a security audit.
Upstream's supported-version statement below describes upstream, not a support
or readiness commitment for Kaythem changes.

Report Kaythem-fork vulnerabilities through
[confidential GitHub vulnerability reporting](https://github.com/Kaythem/rust-libp2p/security/advisories/new).
Do not disclose credentials, live node configuration, internal network/deployment
details or unresolved deployment vulnerabilities in public issues, pull requests,
comments, logs or attachments. The fork's ordinary issue tracker and discussions
are disabled. Keep private material out of reports unless needed and explicitly
requested through the confidential process.

For vulnerabilities in upstream libp2p, follow the upstream policy below.
A private report is not authorization to publish its contents; coordinate any
public disclosure with the responsible maintainers.

---

# Security Policy

## Supported Versions

By default we provide security patches for the latest released version only. On request we patch older versions.

## Reporting a Vulnerability

Please do not file a public issue on GitHub. Instead, please [file a private security vulnerability report](https://github.com/libp2p/rust-libp2p/security/advisories/new).
